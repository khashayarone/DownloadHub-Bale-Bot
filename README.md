# DownloadHub - ربات دانلودر حرفه‌ای برای بله

ربات هوشمند دانلود محتوا از پلتفرم‌های مختلف با قابلیت مدیریت صف، کش هوشمند، و پنل ادمین کامل.

## امکانات کلیدی
- 🎬 دانلود از YouTube (کیفیت 720p, 480p + زیرنویس)
- 🎵 دانلود از SoundCloud (MP3, M4A, Opus, FLAC)
- 📸 دانلود از Instagram (پست، ریل، استوری، IGTV)
- 🎵 دانلود از TikTok (بدون واترمارک)

## قابلیت‌های فنی
- ⚡ کش هوشمند (ارسال آنی از ریپازیتوری)
- 📊 سیستم صف با اولویت (آماده برای Premium)
- 🔄 گزارش پیشرفت زنده دانلود
- 🎨 حالت شب (Dark Mode) برای پیام‌ها
- 🏆 سیستم امتیازدهی و گیمیفیکیشن
- 📡 پنل ادمین تحت وب با نمودارهای لحظه‌ای
- 📨 ارسال همگانی با رعایت محدودیت نرخ

## معماری
- PHP 8.1+ (سازگار با هاست سی‌پنل)
- MySQL (یا MariaDB)
- GitHub Actions (پردازش دانلودها)
- API رسمی بله

## نصب سریع
1. ریپازیتوری را کلون کنید
2. فایل `install.php` را اجرا کنید
3. توکن‌ها را در `config.php` تنظیم کنید
4. Webhook را در @botfather تنظیم کنید: `https://yourdomain.com/downloadhub/webhook.php`
